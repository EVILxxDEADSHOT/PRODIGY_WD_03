# Tic-Tac-Toe Web Application

This is a simple **Tic-Tac-Toe** game built with HTML, CSS, and JavaScript. The game allows two players to compete against each other by taking turns to place their markers (X or O) on a 3x3 grid.

-------------------------Features-------------------------------

- **Interactive Grid**: Players click on cells to make their moves.
- **Win Detection**: The game checks for a winner after every move.
- **Tie Detection**: The game declares a tie if the grid is full without a winner.
- **Restart Functionality**: Players can reset the game at any time.

---------------------------------Files----------------------------

- `index.html`: The HTML structure of the Tic-Tac-Toe application.
- `styles.css`: The CSS styles for the application.
- `script.js`: The JavaScript logic to handle game function.
